# Development rules

Use TypeScript strict mode and documented Lexicon APIs. Never mutate a personal library during tests. Keep handwritten source and test files below 400 lines. Preserve imported cue/grid data. Every completed step needs relevant passing checks, a Conventional Commit, and an immediate push. The repository is public: successful main builds publish prereleases, and manual builds can publish prereleases or stable GitHub releases. npm publishing remains disabled. New behavior requires focused tests and matching documentation.
